Setup

FrøstRGB drives your other components through OpenRGB:
1. Install and open OpenRGB.
2. In OpenRGB: SDK Server → Start Server (port 6742), and tick Start server under Settings so it stays on.
3. Close MSI Center / Mystic Light and other RGB apps, or they will fight over the colors.
